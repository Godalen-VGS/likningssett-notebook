# Likningssett med to ukjente

🔴 Utfordringsoppgave. Løs lineære likningssett, og finn ut når det ikke finnes én entydig løsning.

Åpne [`oppgave.ipynb`](./oppgave.ipynb) i VS Code (eller via Codespaces: knappen "Code" → "Codespaces" øverst på denne siden) for å komme i gang.

Denne oppgaven har automatisk retting. Kjør "Test løsningen din"-cellen nederst i notebooken når som helst for umiddelbar tilbakemelding — samme sjekk kjøres automatisk når du leverer inn.
